🖨️ Task 1 — Digitise Your Prints
Goal: bring your prints into Photoshop.
Scan
  1. 300 dpi or higher
  2. Colour mode (even for black)
  3. Print lies flat
  4. Save as JPG, PNG or TIFF

No scanner? Phone photo · from above · good light · no shadows.

Set up
  1. New document: A3 landscape · 300 dpi
  2. File → Place Embedded
  3. Duplicate the layer Cmd/Ctrl+J
  4. Save as PSD

  • Tolerance 20–40
  • Shift add · Alt/Opt remove
Polygonal Lasso L

Straight edges

  • Join back to the start

🎭 Task 3 — Masks, Blend Modes & Colour
Goal: control your texture. Mix it into the page. Add colour.

Steps — click to open

Image not found:
layer-mask.jpg
🔍 Enlarge
  1. Layers panel → Add Layer Mask
  2. Black brush = hide
  3. White brush = show again

Layers panel → change Normal to:

MultiplyDarker · best on light backgrounds
OverlayMore contrast
ScreenLighter
Soft LightGentle contrast

Use Opacity to make it softer.

  1. Image → Adjustments → Hue/Saturation
  2. Tick Colorize
  3. Move the sliders
💡 Quick colour
  • Put a colour fill layer underneath
  • Set the texture to a blend mode
